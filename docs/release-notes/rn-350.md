### Chat with Your Gmail

Clairify's chat interface ("Claire") now speaks Gmail. Ask Claire to find, filter, or summarize messages in your inbox using natural language — no need to leave the app for a Gmail search. Powered by our new Gmail MCP integration in the Claire chat pipeline.

### Auto-Reply Drafts

Introduced in 3.4.0: Clairify can now draft a reply to any email for you. Pick a tone — formal, casual, and so on — and Clairify generates a draft you can review, edit, and send.

### Compose New Emails from Mobile

Alongside Reply and Reply All, the mobile app now includes a Compose action so you can start a new email without leaving the app. Enter the recipient manually, draft the body, and use AI Rewrite to polish before sending. You can always revert to your original draft.

### Report Bugs from a Screenshot

Spotted something off? Take a screenshot and share it to Clairify by shaking the app, or find the bug report form in the settings menu. We'll bundle your report with your device type, iOS version, and Clairify build and file it to our defect board automatically.

### Better Prompt Authoring

A batch of improvements to summarization-prompt authoring in the web admin panel:

- Rejected prompts now tell you which validation rule was broken, so you can fix them.
- "Re-write with AI" now produces prompts that pass validation.
- The validator no longer rejects reasonable summarization instructions like "skip bullets" or fallback text.

### Branded Login Domain

The mobile SSO flow now shows `auth.clairify.ai` instead of a random Supabase subdomain.

### App Update Nudge

The app now knows about the latest release. When a newer version is available you'll see an informational prompt; when a specific version requires a mandatory update, we'll gate access until you upgrade so you're always running a supported build.

### Text-to-Speech Usage on Mobile

The mobile app now shows your text-to-speech (TTS) usage in audio minutes — both what you've used this period and your plan allowance — alongside existing token metrics.
